# GigLink — Band & Event Booking Platform

GigLink connects bands and solo artists with restaurants, venues and event organizers.
Artists publish a stage profile, browse the gig board and apply with their own offer;
organizers post gigs, review applications and book acts directly.

## Features

- Role-based accounts: band, solo artist, organizer/restaurant, admin
- Artist profiles with genres, rates, media links and reviews
- Venue management with capacity and expected attendance
- Gig board with genre, city, date and payment filters
- Two-way booking: organizer invitations and artist applications/offers
- Ratings and reviews, plus an admin console over users, artists and bookings

## Development

Requires Node.js and npm.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
